অনলাইন সার্ভারে তোলার গাইড (পিসি বন্ধ থাকলেও চলবে)
=====================================================

সতর্কতা:
 - পাসওয়ার্ড অবশ্যই দেবেন। না দিলে সার্ভার চালুই হবে না, আর দিলে শুধু আপনি ঢুকতে পারবেন।
 - cookies.txt কখনো GitHub-এ তুলবেন না (.gitignore এ বাদ দেওয়া আছে)। ওটা আপনার লগইন।
 - অনেক হোস্ট তাদের নীতিতে ডাউনলোডার বা অ্যাডাল্ট কনটেন্টসংক্রান্ত সার্ভিস বন্ধ করে দেয়। হোস্টের Acceptable Use Policy পড়ে নিন।
 - ক্লাউড সার্ভারের আইপি অনেক সাইট ব্লক করে (403/429)। তখন YTDLP_PROXY লাগবে।

পথ ১: Render (সবচেয়ে সহজ, ফ্রি ট্রায়ালের জন্য)
 1. github.com এ একটা PRIVATE রিপোজিটরি বানান, eror ফোল্ডারের ফাইলগুলো তাতে আপলোড করুন।
 2. render.com এ সাইন আপ করুন > New > Blueprint (বা Web Service) > আপনার রিপো বেছে নিন।
 3. Environment এ EROR_PASSWORD দিন (আপনার গোপন পাসওয়ার্ড)। দরকার হলে YTDLP_PROXY দিন।
 4. Deploy চাপুন। কয়েক মিনিট পর একটা https লিংক পাবেন।
 5. লিংক খুলুন। ইউজারনেম ফাঁকা রাখুন, পাসওয়ার্ড দিন। উপরে "Server connected" দেখালে ঠিক আছে।
 6. Android/Windows এর Chrome এ ⋮ > Install app দিলে অ্যাপের মতো বসবে।
 সীমা: ফ্রি প্ল্যান ১৫ মিনিট ব্যবহার না হলে ঘুমিয়ে যায়, আবার খুললে ১ মিনিটের মতো লাগে। ডিস্ক অস্থায়ী, তাই নামানো ফাইল ৩ ঘণ্টা পর মুছে যায় (এটা ইচ্ছাকৃত)।

পথ ২: নিজের VPS (সবচেয়ে স্থিতিশীল, মাসে প্রায় ৫ ডলার)
 1. যেকোনো VPS নিন (Ubuntu), Docker ইনস্টল করুন।
 2. ফাইলগুলো সার্ভারে আপলোড করে eror ফোল্ডারে গিয়ে চালান:
      docker build -t eror .
      docker run -d --restart=always -p 80:10000 -e EROR_PASSWORD=আপনার_পাসওয়ার্ড eror
 3. http://সার্ভারের-আইপি খুলুন। (https চাইলে Caddy বা Cloudflare সামনে বসান।)
 --restart=always থাকায় সার্ভার রিবুট হলেও নিজে চালু হবে।

ঠিক আছে কিনা দেখতে: লিংকের শেষে /api/health যোগ করে খুলুন (পাসওয়ার্ড লাগবে)।


২৪ ঘণ্টা চালু রাখা
 - সার্ভারে নিজে থেকে পিং চালানোর ব্যবস্থা যোগ করা আছে। Render-এ নিজে থেকেই কাজ করে (RENDER_EXTERNAL_URL ব্যবহার করে)। অন্য হোস্টে KEEPALIVE_URL এ আপনার লিংক দিন।
 - এর পরেও নিশ্চিত থাকতে uptimerobot.com এ ফ্রি অ্যাকাউন্ট খুলে একটা HTTP monitor বানান: লিংক = আপনার-লিংক/api/ping, ইন্টারভাল ৫ মিনিট। এটা বাইরে থেকে সার্ভারকে জাগিয়ে রাখে আর বন্ধ হলে জানায়।
 - পুরোপুরি নিশ্চিত ২৪/৭ চাইলে VPS (পথ ২) নিন। ফ্রি প্ল্যানে মাঝে মাঝে রিস্টার্ট হতে পারে।
