ইরোর (Eror) সার্ভার
====================

কম্পিউটারে চালানো
  1. Python ইনস্টল করুন (python.org, "Add Python to PATH" টিক দিন)।
  2. start.bat-এ ডাবল ক্লিক করুন। Chrome খুলবে আর উপরে ডানে "Server connected" দেখাবে।
  3. যদি "No server" দেখায়, তাহলে পেজটা ভুলভাবে খোলা হয়েছে। index.html-এ ডাবল ক্লিক করবেন না, সবসময় start.bat দিয়ে খুলুন।
  4. কোনো সাইট হঠাৎ কাজ না করলে update.bat চালান।

নিজের কম্পিউটার থেকে অস্থায়ী অনলাইন লিংক (ট্রায়ালের জন্য)
  start-online.bat-এ ডাবল ক্লিক করুন, একটা পাসওয়ার্ড দিন, তারপর trycloudflare.com লিংকটা ব্যবহার করুন।
  কম্পিউটার চালু আর উইন্ডো খোলা থাকতে হবে। লিংক প্রতিবার বদলায়।

নিজের অনলাইন সার্ভারে তোলা (হোস্টিং)
  1. এই ফোল্ডারের সব ফাইল হোস্টে আপলোড করুন (Dockerfile আছে, Docker চালায় এমন যেকোনো হোস্টে চলবে)।
  2. হোস্টে এই এনভায়রনমেন্ট ভ্যারিয়েবল দিন:
       EROR_PASSWORD = আপনার পাসওয়ার্ড (এটা ছাড়া সার্ভার চালু হবে না, ইচ্ছা করেই)
       YTDLP_PROXY   = (ঐচ্ছিক) প্রক্সি ঠিকানা, যেমন http://user:pass@host:port
  3. লিংক খুললে ব্রাউজার ইউজারনেম আর পাসওয়ার্ড চাইবে। ইউজারনেম ফাঁকা রাখুন।
  4. পেজের উপরে ডানে "Server connected" দেখালে সার্ভার ঠিক আছে।

অনলাইনে ভিডিও না এলে
  - অনেক সাইট ক্লাউড/ডেটা-সেন্টার সার্ভার থেকে আসা অনুরোধ ব্লক করে। এরর লেখায় 403 বা 429 দেখা গেলে এটাই কারণ।
    তখন নিজের কম্পিউটারে চালান, অথবা YTDLP_PROXY দিয়ে অন্য আইপি ব্যবহার করুন।
  - http://আপনার-লিংক/api/health খুললে দেখতে পাবেন yt-dlp আর ffmpeg ঠিক আছে কি না।

নতুন যা যোগ হয়েছে
  - লিংক বক্সে ✕ বাটন: চাপলে লিংক মুছে যায়।
  - "✕ Close video" বাটন (বা Esc চাপুন): চলতে থাকা ভিডিও বন্ধ হয়ে প্লেয়ার খালি হয়ে যায়।
  - নতুন রঙিন ডিজাইন।
  - yt-dlp যে সাইট চিনতে পারে না, সেখানে সার্ভার নিজে পেজের ভিতর থেকে ভিডিও ফাইল (mp4/m3u8) খুঁজে নামানোর চেষ্টা করে।
    তাও না হলে সাইটটা সার্ভারকে ব্লক করছে, তখন update.bat চালান অথবা নিজের পিসিতে চালান।

ডাউনলোড (নতুন)
  - লিংক বসিয়ে কোয়ালিটি বেছে "⬇ Download" চাপুন। YouTube, TikTok, Instagram, Facebook সহ yt-dlp যে সাইট চেনে সবখানে কাজ করবে।
  - শুধু গান চাইলে "Audio only (MP3)" বেছে নিন।
  - TikTok: ওয়াটারমার্কওয়ালা কপি বাদ দিয়ে ওয়াটারমার্কহীন কপি নামানো হয়। শুধু ওয়াটারমার্কওয়ালা কপি থাকলে সার্ভার নামাবে না, এরর দেখাবে।
  - Instagram আর Facebook নিজেরা ফাইলে কোনো ওয়াটারমার্ক বসায় না। তবে এরা প্রায়ই লগইন চায় বা ক্লাউড সার্ভার ব্লক করে।
    তখন: ব্রাউজার থেকে cookies.txt এক্সপোর্ট করে (যেমন "Get cookies.txt LOCALLY" এক্সটেনশন) এই ফোল্ডারে cookies.txt নামে রাখুন।
    অনলাইন হোস্টে ফাইল রাখতে না চাইলে YTDLP_COOKIES_B64 এনভায়রনমেন্ট ভ্যারিয়েবলে cookies.txt-এর base64 দিন।
    cookies.txt আপনার লগইন, তাই কাউকে দেবেন না।
  - শুধু নিজের ভিডিও বা যেগুলো নামানোর অনুমতি আছে সেগুলো নামান। অন্যের ভিডিও আবার পোস্ট করলে কপিরাইট সমস্যা হতে পারে।

মোবাইলে অ্যাপ হিসেবে (APK)
  সবচেয়ে সহজ: সাইটটা অনলাইনে (https) তুলুন। Android-এ Chrome-এ খুলে ⋮ মেনু > "Install app" (বা "Add to Home screen") চাপুন।
  হোম স্ক্রিনে Eror আইকন আসবে, অ্যাড্রেস বার ছাড়া অ্যাপের মতো খুলবে। এটা আসলে Chrome-এর বানানো WebAPK।
  নিজস্ব .apk ফাইল চাইলে: pwabuilder.com-এ সাইটের লিংক দিয়ে Android প্যাকেজ বানান। সেই সময় সাইটে ব্রাউজারের পাসওয়ার্ড চাওয়া থাকলে ওটা ওয়েবসাইট পড়তে পারবে না।

পুরো চ্যানেল / পেজ / প্লেলিস্ট ডাউনলোড (নতুন)
  - লিংক বসিয়ে "Single video"-র জায়গায় "Whole channel / page / playlist" বেছে নিন। পাশের ঘরে কতগুলো ভিডিও নামাবেন লিখুন (নতুন থেকে পুরনো, ডিফল্ট ২০, সর্বোচ্চ ১০০)।
  - সার্ভার একটা একটা করে ভিডিও নামায়, শেষে সব একটা ZIP ফাইলে দেয়। নামানোর সময় পেজ খোলা রাখুন। "Cancel" চাপলে চলতি ভিডিওর পর থেমে যায়, যতটুকু নামেছে তার ZIP পাবেন।
  - যেসব ভিডিও নামেনি সেগুলোর তালিকা ZIP-এর ভিতরে failed.txt ফাইলে থাকবে।
  - YouTube: চ্যানেল লিংক (youtube.com/@নাম) বা প্লেলিস্ট লিংক দিন। TikTok, Vimeo, Dailymotion, X ইত্যাদির প্রোফাইল/প্লেলিস্টও yt-dlp যতটা চেনে ততটা কাজ করবে।
  - Reddit: সাবরেডিট (reddit.com/r/নাম, চাইলে /top/?t=week) বা ইউজার (reddit.com/user/নাম) লিংক দিন। শুধু ভিডিও পোস্টগুলো নামবে। Reddit অনেক সময় অনলাইন সার্ভার ব্লক করে, তখন নিজের কম্পিউটারে চালান অথবা YTDLP_PROXY দিন।
  - Facebook: পেজ লিংক (facebook.com/পেজের-নাম) দিন। Facebook সার্ভারকে প্রায় সবসময় লগইন ছাড়া ভিডিও তালিকা দেখায় না, তাই cookies.txt (উপরে লেখা আছে) রাখা ভালো। তাও সব ভিডিও না-ও আসতে পারে, তখন আলাদা আলাদা ভিডিও লিংক দিন।
  - সীমা বদলাতে হোস্টে এনভায়রনমেন্ট ভ্যারিয়েবল: EROR_MAX_CHANNEL (সর্বোচ্চ ভিডিও সংখ্যা, ডিফল্ট ১০০), EROR_CH_MAX_FILESIZE (প্রতি ভিডিওর সর্বোচ্চ বাইট, ডিফল্ট ১ জিবি)।
  - ফ্রি অনলাইন হোস্টে ডিস্ক আর সময় কম থাকে, বড় চ্যানেল নিজের কম্পিউটারে (start.bat) নামানোই ভালো।
